# Kế hoạch 2: Admin UI (React TS + Ant Design)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Xây trang quản trị để cán bộ tuyển sinh dùng toàn bộ API của kế hoạch 1: đăng nhập, thêm/sửa/xóa bản nháp 10 loại tri thức, nhập CSV/Excel, xem thay đổi và xuất bản/khôi phục release. Kèm theo đó là sửa lỗi múi giờ `+07:00` còn tồn từ kế hoạch 1.

**Architecture:**
- Một SPA React TypeScript (`frontend/apps/admin`) trong pnpm workspace, gọi API qua đường dẫn tương đối `/api`.
  - Khi dev: Vite proxy chuyển `/api` sang backend.
  - Khi triển khai: phục vụ cùng origin sau reverse proxy, nên backend **không cần CORS**.
- Trang CRUD được sinh từ cấu hình (`entityConfigs`), giống `KbEntityDefinitions` ở backend: một component chung `KbEntityPage` cộng mười cấu hình.
- Dữ liệu server quản lý bằng TanStack Query.

**Tech Stack:**
- Node 22, pnpm 10, React 18.3, TypeScript 5 (strict), Vite 5
- Ant Design 5 (locale `vi_VN`), dayjs (locale `vi`, plugin timezone), React Router 6, TanStack Query 5
- Vitest 2 + @testing-library/react 16 + MSW 2 + jsdom
- Playwright cho e2e (Chromium có sẵn trong môi trường)

**Spec:** `docs/superpowers/specs/2026-11-05-tdmu-voice-advisor-design.md`, mục 7 (Admin), 4.1 (release), 4.3 (nhập liệu), 10 (bảo mật). Việc tồn đọng: `docs/superpowers/plans/p1-followups.md`.

## Global Constraints
- **Ngôn ngữ:** toàn bộ chữ hiển thị là tiếng Việt. `ConfigProvider locale={viVN}`; dayjs locale `vi`.
- **Gọi API:** chỉ qua `apiFetch` (Task 3) với base tương đối `/api`. Vite dev proxy `/api` → `process.env.VITE_API_TARGET ?? "http://localhost:5110"` (cổng `http` trong launchSettings của backend). Không thêm CORS vào backend.
- **Token:** lưu ở `sessionStorage`, key `tdmu-admin-auth`, giá trị JSON `{ accessToken: string, expiresAt: string }`. Không dùng `localStorage`. Không ghi token ra console.
- **Thời gian:** hiển thị theo `Asia/Ho_Chi_Minh`. Gửi lên API dạng ISO 8601 có offset; backend lưu UTC (Task 1).
- **Số:**
  - Ô nhập số chấp nhận dấu phẩy thập phân (`21,5`) và hiển thị theo vi-VN.
  - Điểm: tối đa 2 chữ số thập phân.
  - Học phí: số nguyên, hiển thị có phân cách nghìn (`1.200.000`).
- **Nhãn enum** (giá trị API giữ nguyên):
  - `DonViHocPhi`: `"TinChi"` → "Tín chỉ", `"Nam"` → "Năm", `"HocKy"` → "Học kỳ"
  - `DiffKind`: `"Added"` → "Thêm", `"Modified"` → "Sửa", `"Removed"` → "Xóa"
- **Lỗi từ API (ProblemDetails):**
  - 400: map `errors[field][0]` vào đúng `Form.Item name={field}`. Key là camelCase giống DTO, ví dụ `diem`, `thangDiem`.
  - 409: hiện `title`, cùng danh sách `thamChieu` nếu có.
  - 401: đăng xuất và về `/login?returnTo=<đường dẫn hiện tại>`.
  - Lỗi khác: `message.error(title)`.
- **TypeScript:** `strict: true`. Không dùng `any` trong `src/` (cho phép trong test helper). Lint bằng `tsc --noEmit`.
- **Test:**
  - Test component dùng MSW, gọi đúng đường dẫn API thật.
  - Mỗi task frontend phải để `pnpm -C frontend test` và `pnpm -C frontend typecheck` xanh.
  - Task 1 (backend) phải để `dotnet test backend` xanh.
- **Commit:** mỗi task một hoặc vài commit; message kết thúc bằng hai dòng attribution của phiên.
